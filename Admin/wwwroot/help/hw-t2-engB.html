Tool 2 Single Concept MRP applies the same Colour STR logic as Tool 1 Single Concept MRP — but assesses an already-raised PO. The released PO qty is already in F2, so the system assesses whether retaining, reducing, or cancelling makes sense.
Tool 1 — Prospective
Proposed PO qty injected into the chain in the DM month.
Window starts Day 1 of (Delivery Month + 1).
Decision: Allow / Reduce / Hold.
Tool 2 — Retrospective
Released PO already in F2 — not injected separately.
Window starts Day 1 of (Delivery Month + 1) — same rule as Tool 1.
Decision: Retain / Reduce Qty / Cancel.
1
F1 Op Stock — same rule as Tool 1
SUM all F1 rows for KEY-3. Multiple RDC rows summed. F1 reflects sales up to today.
2
Colour Mix % Gate
Same as Tool 1: daily F3 data used when present (SUM Day1..DayN ÷ {{MWD}}), else monthly average (last N={{N}} months). Mix% < {{MIX}}% → Watch List.
3
Pre-roll to window start (Delivery Month + 1)
Current month: remaining days demand only. Future months: full month demand. Released PO already in F2 — no separate injection.
4
{{D}}-day window & Daily Rate
Same formula as Tool 1: SUM of colour demand (F4 × Mix%) over next {{D}} days from window start ÷ {{D}}.
5
Colour STR & Max Permissible
STR = (Stock at window start ÷ {{D}}-day demand) × {{D}}. Breach if STR > T×(1+Buffer%) (Effective T = {{EFFT2}}d by default). Max Permissible = MAX(0, T×(1+Buffer%) × Daily Rate − Stock w/o this PO) — uses the same buffered Effective T as the breach test. Stock already includes released PO via F2, so it's subtracted back out before this calculation.
✓ Retain
STR ≤ Effective T (T×(1+Buffer%), default {{EFFT2}} days). Released PO is within cover threshold — keep it.
↓ Reduce Qty
STR > Effective T but Max Permissible > 0. Amend PO down to Max Permissible units. Cancel the balance.
❌ Cancel
STR > Effective T AND Max Permissible = 0. Existing stock (without this PO) already exceeds the effective threshold (default {{EFFT2}} days). Cancel entire released PO quantity.
Example (Cancel): GM 1112044799, MBU, released PO 722 units, DM Jun 2026. Op Stock=87,512. Mix%=13.11%. Jun remaining=969 units demand. Stock at Jul 1=87,265. 60-day demand=22,742. Daily Rate=379/day. STR=87,265÷379=230d >> effective {{EFFT2}}d (T={{T2}} + {{BUF}}%). Max Perm=MAX(0,{{T2_CALC}})={{T2_RESULT}} → Cancel.
