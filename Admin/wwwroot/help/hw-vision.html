Purpose
Why does this tool exist?
Every PO raised without a demand check risks overstock — money locked in slow-moving inventory, forced markdowns, and lost shelf space for better sellers. This tool runs the same logic the Planning team uses — sell-through benchmarking and rolling stock cover — so every category planner can validate in under 30 seconds before committing to a vendor.

Two tools, one continuous loop: Tool 1 prevents bad POs from being raised. Tool 2 catches POs that were correct when raised but have since gone stale due to poor sell-through.
🛡 Tool 1 — PO Raise Validation
When: Before you raise a new PO
Question: Should I raise this colour at this quantity?
Input: Generic Material + Colour + Delivery Month + Proposed Qty
Engines: Multi Concept MRP (peer ranking) or Single Concept MRP (stock cover)
Outcomes: Allow · Reduce Qty · Hold · Watch List · Block
🔍 Tool 2 — Raised PO Assessment
When: Periodically — review all open released POs
Question: Should existing POs be retained, reduced, or cancelled?
Input: Batch upload of released PO file
Engines: Same Multi Concept MRP and Single Concept MRP, applied to released qty
Outcomes: Retain · Reduce Qty · Cancel · Watch List
Routing — How the system decides which engine to use
Two-step engine routing — runs on every article
S1 Universe Master check — Is the Generic Material in the Universe Master? (Key: Brand × MC × MRP × BOGO × Generic Material)
✓ Found → Single Concept MRP (Colour STR). No further check needed.
✗ Not found → Go to Step 2.
S2 CY BSR check (Tool 1 only) — Is the Generic Material in the Current Year Best Seller Report?
✓ In CY BSR → Multi Concept MRP (Peer ranking — True Repeat or BOBs)
✗ Not in BSR → Auto Allow (Genuinely new article — no sell-through history)
Note: Tool 2 skips Step 2 — no UM match goes straight to Multi Concept MRP.
System Parameters — configurable by Planner
Key thresholds that drive all decisions
Parameter
Default
What it controls
T — STR Threshold
T1(Tool1)={{T1}}d · T2(Tool2)={{T2}}d
Base cover threshold. Used in Max Permissible formula. Breach triggers at T × (1 + STR Buffer%). Tool 1 (PO Raise Assessment) and Tool 2 (Raised PO Assessment) each use their own independent threshold.
STR Buffer % (Single Concept MRP)
5%
Tolerance above T before breach is triggered. Effective threshold: Tool 1 = {{EFFT1}}d, Tool 2 = {{EFFT2}}d. Max Permissible also uses this same effective threshold: MAX(0, T×(1+Buffer%) × Rate − StockNoPO).
Border Zone % (Multi Concept MRP)
10%
PDSTR gap tolerance for Q4/Q3 articles. If gap from peer avg ≤ 10%: Q3 → Allow, Q4 → Watch List instead of hard decision.
D — Window
60 days
Forward days to accumulate demand from Day 1 of the STR window start (Delivery Month + 1), used for both the Daily Rate divisor and the STR multiplier.
Mix % Gate
2%
If colour share of MC sales < 2% → broken/cut sizes → Watch List.
WOF Gate
4 weeks
Minimum weeks on floor before an article is ranked in peer group.
Peer Min
5 styles
Min peer pool size. If the current season(s) have fewer than 5 qualifying styles → the fallback season(s) chosen in Season Selection are used (rule: the same season last year, e.g. AW26 → AW25, SS26 → SS25).
Mix Window
45 days (Day 1...Day N)
F3 supplies Day 1 (oldest) through Day N (most recent) sales columns, refreshed before each upload. Tool sums all day-columns. Falls back to last N=2 months avg if F3 has only monthly columns.
Abs. Block PDSTR
< 1%/day
PDSTR < 1%/day with WOF ≥ 4 weeks → Absolute Block regardless of quartile.
Input Files — uploaded by Planner before buyers can validate
What each file provides
F1 — Stock
Current physical stock as-of-today at colour level (KEY-3). Multiple RDC rows summed.
F2 — Pending PO
All released/pending POs with delivery month and quantity. Feeds Tool 1 and Tool 2.
F3 — Sales Trend
Day 1 (oldest) to Day 45 (most recent) sales at colour level — refresh before each run. Sum of all 45 columns used to compute Colour Mix % for Single Concept MRP. Monthly MM.YYYY columns are also accepted.
F4 — Forecast
Forward MC-level demand forecast by month — split to colour level using Mix %.
Universe Master
Routing master: Brand × MC × MRP × BOGO × Generic Material. Determines Multi Concept MRP vs B.
CY BSR (SS26)
Current year Best Seller Report — option type detection and peer ranking in Multi Concept MRP.
BSR — fallback season
BSR of the fallback season(s) chosen in Season Selection — used as the peer pool when the current season has < 5 qualifying styles.
Article Master (opt)
Generic Material → Style/Fit/Product Material/Design attribute values, plus Article/Vendor description. Powers the Multi Concept MRP recommendation engine (see Tool 2 · Recommendations tab).
Attribute Relevance Master (opt)
Brand × MC × MRP × Flag → which attribute (Style/Fit/Product Material/Design/Colour-only) is the meaningful ranking lens for that bucket. Without an entry for a given bucket, the recommendation engine falls back to plain colour-level STR.
Colour Master (opt)
Colour code → description, for readable labels in exports.
Cat Head Mapping (opt)
Brand × MC CD × MRP → responsible Category Head (by email). Drives the per-person sheets and Quick Links in the Tool 2 Excel export. Unmapped combinations fall under "Unassigned".
