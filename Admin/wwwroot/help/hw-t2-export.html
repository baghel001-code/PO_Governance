Everything on this tab is downstream of the Retain/Watch List/Reduce/Cancel decision — it never changes what was decided. It covers: (1) how the system recommends what to switch to for a Reduce/Cancel line, (2) how the Excel export is organised, and (3) what's bundled in for further analysis.
1
Multi Concept MRP — Colour/GM Recommendation Engine
What should this Reduce/Cancel line switch to instead? (the "Option 1/2/3" columns)
Driven by
Attribute Relevance Master
For each Brand × MC × MRP × Flag bucket, this file names which product attribute is the meaningful lens for ranking within that bucket — Style, Fit, Product Material, Design, or Colour-only (no attribute tier at all, judge by colour directly). Article Master supplies each Generic Material's actual value for whichever attribute is named.
1
Rank attribute values by deviation
Within the MC×MRP bucket, each attribute value (e.g. each Style) is ranked by Sale Mix% − Stock Mix% deviation — attribute values selling faster than they're stocked rank first.
2
Rank colours within the best attribute value
Inside the top-ranked attribute value, colours are ranked by their own colour-level STR (stock-cover days) — lowest (fastest-moving) first.
3
Cross-verify each candidate against BSR
A candidate colour only gets recommended if it can be genuinely confirmed as Q1 (top quartile) in the Best Seller Report — falling back to Q2 only if no Q1 candidate clears. This is the same BSR peer-ranking engine Tool 1/Tool 2's own decisions use, just run in reverse to find a good option instead of judging the current one.
Q1 candidate found → recommended, Priority 1No Q1, but Q2 candidate found → recommended, Priority 2
Fallback path — when the fuller detail isn't shown
If any of these apply for that row's own MC×MRP×Brand×Flag bucket, the recommendation instead falls back to plain colour-level STR ranking across the whole bucket — no quartile or PDSTR shown, since that data genuinely wasn't verified for this bucket:
• No entry in Attribute Relevance Master for that exact Brand×MC×MRP×Flag combination
• The dimension listed is "Colour-only"
• Nothing in that bucket could actually be confirmed as Q1 or Q2 in the BSR

This is why two Reduce/Cancel rows can show different Option formats — GM / COLOUR (Q1, STR 10d, PDSTR 3%/day) — Style vs the simpler GM / COLOUR (STR 61d) — depending on what's actually available for each row's own bucket, not a bug.
Exploration only — Recommendation screen
On the live Recommendation drill-down (click a row after a decision is made), a dropdown next to "Dimension: X" lets you manually switch to any of the 4 attributes to see what the ranking and recommendations would look like under a different lens. The dimension Attribute Relevance Master actually calls for is always marked "(Relevant)" and is what's shown by default. Switching it only changes what that screen displays — it never changes the row's actual stored decision.
Example: MC L_EW_MM_KURTA, MRP ₹299 has an Attribute Relevance Master entry for "Style" and a colour that verifies Q1 → Option 1 shows the full quartile/PDSTR detail. MC KB_SR_BRIEF, MRP ₹79 has no entry in Attribute Relevance Master for that bucket → falls back to plain colour STR ranking.
2
Excel Export — Structure & Navigation
One workbook per Tool 2 run, organised by Category Head
1
Summary Dashboard (first tab)
KPI summary, decision mix, driver breakdown, MC risk table, and a filterable Quick Links table — one row per Category Head × Type × Sub-Category, colour-coded per person and per Type (Watchlist=amber, Reduce/Cancel=red), each with a "→ Open" link straight to that person's sheet. Filter by any column's dropdown to narrow the list before clicking through.
2
One sheet per Category Head × Type
Watchlist splits into BoBs / True Repeat / Single Concept per person. Reduce/Cancel merges into Single Concept and Multi Concept per person (Reduce Qty and Cancel share one sheet, disambiguated by the Decision column) — a Multi Concept row that happens to get "Reduce Qty" folds into that person's Multi Concept sheet too, so nothing is ever silently dropped. Empty combinations are skipped — no sheet is created for a person with zero items in a bucket.
3
Category Head Mapping (optional input)
Matches each row to its Category Head on Brand × MC CD × MRP (Flag is not part of the match). Anything that doesn't match falls under "Unassigned", sorted to the end — never dropped. If this file isn't uploaded, everything falls under "Unassigned".
4
Category Head export filter
A multi-select dropdown next to the Excel button scopes the entire export to just the Category Head(s) you pick — Summary KPIs, the sheet list, and All Decisions all narrow to match. Leave it empty to export everyone, as before.
5
Colour-wise Stock & PO Recommendation table
Appended inside each person's Reduce/Cancel × Single Concept sheet — one table per MC×MRP they own with a Reduce Qty item. Ranked Stock High to Low, with month-wise Pending PO and Max Permissible Qty per colour. Watch-List-flagged colours are excluded (they're covered in that person's own Watchlist sheet instead).
6
Power BI star schema & DAX measures
Every export also bundles a Fact/Dimension data model (Fact_Decisions + Category Head / MC / Engine / Month dimensions) plus a library of ready-to-paste DAX measures and a one-page dashboard build guide — for whoever wants to build a Power BI (or Excel Power Pivot — same DAX engine, no separate install needed) view on top of this run.
7
All Decisions (last tab)
The complete, unfiltered master list of every line assessed — kept as the audit trail, always last so the action-oriented sheets come first.
3
Raw Data Import
Straight-from-system exports can be zipped in alongside already-formatted files
Put raw system exports (Stock, Pending PO, Sales Trend, Article Master, multi-brand Best Seller Report workbooks) and already-formatted input files together in one ZIP and upload it once. Each file is inspected by its actual columns, not its name — recognised raw shapes are auto-converted (renamed columns, date-columns turned into Day 1...Day 45, multi-brand BSR files combined into one), and anything already in portal format is matched by filename as before. Multiple Best Seller files for the same season combine into a single CY BSR automatically.
